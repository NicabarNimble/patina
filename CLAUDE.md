## Rules

### AI Workflow
- **NEVER use Claude Code's memory system** (MEMORY.md, ~/.claude/projects/*/memory/) — Patina IS the memory system. Use `layer/sessions/`, `layer/core/`, and `patina scry`/`patina context` instead.
- **NEVER use plan mode** — read code and do the work directly.
- Read code before write code. Spec changes before code changes.
- Before coding: `cargo tree` for existing deps, read existing patterns in use. Don't introduce new dependencies when the solution is already compiled into the binary.

### Rust-First
- Pure Rust at runtime, no Python subprocess dependencies.
- Embeddings: ONNX Runtime via `ort` crate (not Python/CoreML).

### Testing — IMPORTANT
Always build release and test with live install:
```bash
cargo build --release && cargo install --path . && patina <command>
```

### CI — IMPORTANT
Before pushing, ALWAYS run:
```bash
./resources/git/pre-push-checks.sh
```

### Git Commit
- NEVER add AI attribution to commit messages (no "Generated with Claude Code", no "Co-Authored-By: Claude")
- Commit after each logical change. One commit = one purpose.
- Prefer `git add -p` for surgical staging.
- Run `/session-update` frequently to monitor uncommitted changes.
