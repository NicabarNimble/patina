# patina-is-beliefs-plus-action

Patina's function is beliefs + action. The protocol verbs (capture, index, search, believe, evolve) serve the belief lifecycle. The action layer keeps beliefs alive — evolving, being used, generating new evidence. Without action, beliefs are static documents. Without beliefs, actions are uninformed. A Patina project IS an action layer with a belief layer inside it. There is zero need for a belief layer that isn't actionable.
