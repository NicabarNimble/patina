# Design: Core Values as First-Class Beliefs

## Approach

Distill each core doc into a tight value file (<800B target, 1KB hard limit) in `layer/core/values/`. Add `kind` column to beliefs table and `type: value` detection to scrape pipeline. Values reuse the full belief insertion path with minimal metrics (they're axioms, not claims).
