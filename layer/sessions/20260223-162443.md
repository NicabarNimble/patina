**Discussion context:**
- Used `design.md` as implementation blueprint — the audit session's analysis paid off. Every function signature, every side effect, every git tag convention was already decided. Zero design time during implementation.

- **All 6 new commands added in one commit** (clap stubs) — avoids 6 separate "add stub" commits. Real implementation filled in per-step.
