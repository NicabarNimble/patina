**Key decisions:**
- FTS5 incremental uses `LIKE prefix%` because `source_id` in eventlog is
  `./path.rs::symbol_name`. Exact IN-clause matching would miss all entries.
- Commits FTS5 uses `LEFT JOIN` instead of `NOT IN` subquery — more
  efficient for FTS5 virtual tables.
- AOT cache uses `Engine::detect_precompiled_file()` rather than a separate
  version metadata file — wasmtime validates its own header format.
- Grounding watermark approach (mtime comparison) chosen over per-belief
  path intersection (DESIGN.md Q3) — simpler, same performance benefit.
