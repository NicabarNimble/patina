## Key Decisions Made This Session
1. **github.* schema, not forge.*** — each connector owns its namespace, no generic "forge" in new system
2. **forge-plugin-extraction stays paused** — WASM plugin is needed to prove both runtimes under mother-broker
3. **Three coexisting implementations** during transition: src/forge/ (delete after parity), plugins/forge/ (WASM, stays), children/github-connector/ (native, new)
4. **PipeError codes are transport detail** — public Rust enum has variants only, JSON-RPC codes live in serialization layer
5. **Cursor is opaque** — child owns interpretation, Mother stores without parsing
6. **Credentials use SecretString** — zeroize-on-drop, especially for stream-mode children
7. **Cursor + fact writes are transactional** — same SQLite transaction
8. **No fan-out optimization** — separate child spawns per destination until measured need
9. **DESIGN.md first, then build** — session 0 writes all 5 designs, sessions 1-5 execute
