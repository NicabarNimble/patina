## Discoveries

1. **Host-fed state pattern for constrained WASM children**: When a child needs external state but has no filesystem access (Phase 1 constraint), the host pushes state via `handle()` and the child makes decisions based on that data. The child is a decision engine, not a data collector. This pattern will recur for any Phase 1 child that needs real-world state.

2. **wasm32-wasip2 provides clocks**: `std::time::SystemTime::now()` works in wasm32-wasip2 targets because WASI Preview 2 includes clock imports. The repos child uses this for staleness calculations without needing explicit WASI clock configuration.
