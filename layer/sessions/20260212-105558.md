**Key decisions:**
- Separate `CommandEngine` from `PluginEngine` because command world needs different `HostState` (with layer access). Both share wasmtime::Engine singleton (OnceLock). Per [[separate-worlds-for-isolation]].
- WIT directory-per-world: `wit/mother-child/` and `wit/command/` each with own `deps/` containing hard-linked `host.wit`. Required because WIT parser enforces one package per directory.
- `patina-command-api` as separate crate from `patina-plugin-api` — different traits (`CommandPlugin` vs `MotherChildPlugin`), different worlds, different generated bindings.
- `host_layer` added to auto-granted capabilities list alongside `host_log`.
- `ChildHealth` changed from enum to record with `status: HealthStatus` + `reason: Option<String>` — guest plugins now pass diagnostic strings through the WASM boundary instead of host hardcoding them.

**Challenges faced:**
- WIT `use` syntax for importing types from interfaces into world scope: `use patina:host/types@0.1.0.{child-health, toy};` — had to test compilation to confirm syntax.
- `wit_bindgen::generate!` with `generate_all` auto-generates used types at crate root, causing conflict with explicit `pub use` re-exports — removed the re-exports, only re-export `HealthStatus` which isn't at root.
- Two `bindgen!` macros in same file for different worlds generate conflicting trait names — solved by putting command bindgen in separate `mod command_bindings` with its own `CommandHostState`.
- Guest WIT files are hard links (same inodes), not symlinks as session notes claimed. This is actually better — `mv` preserves inodes so guest crates automatically track directory restructures.

**Patterns observed:**
- WIT directory = WIT package (strict 1:1). Multi-world projects need multi-directory WIT layout.
- Hard links > symlinks for WIT file sharing — inodes survive directory restructures, `diff` and CI checks work transparently.
- Separate HostState per world is the clean pattern for wasmtime multi-world support — each world's host functions may need different state.
