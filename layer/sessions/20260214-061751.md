**Audit Findings (7):**
- **F1** (Critical): Host trait impls copy-pasted across 4 worlds (~700 lines duplicated). Security fixes must be applied 3-4x. LLM workflow fragility multiplier.
- **F2** (Critical): `count_layer_files` path traversal — `../../..` counts `.md` files outside layer tree. Violates [[safety-boundaries]].

- **G5** (Minor): HTTP client builder duplicated in mother-child and task engines.
- **G3** (Minor): `WasmCell<T>` `unsafe impl Sync` has no compile-time guard against WASM threads.
- **F3** (Deferred): Pipeline creates fresh Store per `handle()` call — performance, not correctness.
- **G4** (Deferred): `probe_host_state()` side effects — practically harmless.
- **G2** (Deferred): `QueryDispatchFn` ergonomics — do after F1 centralizes dispatch.

**Key Insight (from Outside Agent 1):**
F1 is not just a Rust fragility — it's an **LLM workflow fragility multiplier**. An LLM assistant editing one world has no structural reason to also edit the other worlds. The compiler doesn't catch impl drift. This is uniquely dangerous for a project built by and for LLMs.
