## Decisions
- **Bounded agency**: Children have agency within their sandbox, but only the agency Mother grants. Not fully autonomous, not fully externally directed. Refines [[children-have-agency-toys-are-capabilities]].
- **Toys = WIT interfaces**: The compile-time WIT contract IS the capability boundary. Runtime grants become defense-in-depth (scoping within a capability), not the primary gate.
- **Per-child worlds**: Each child declares exactly what toys it needs via its own WIT world. The monolithic `knowledge-child` world is retired.
- **GitHub as toy, not child**: Data source access (issues, PRs, sync) is a capability any child composes, not a standalone actor.
- **Interface-child convergence**: Interfaces and children follow the same pattern (bounded capabilities, Mother manages lifecycle). Long-term, interfaces become children with `toy-llm` + `toy-conversation`.
