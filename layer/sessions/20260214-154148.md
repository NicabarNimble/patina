**Key decisions:**
- **wasm32-gated export!**: Workspace builds unify features across consumers (doctor=command, models=mother-child), which causes `export!(Component)` to generate duplicate ABI symbols (`cabi_post_name` etc.) on native. Solution: wrap Component bridge in `#[cfg(target_arch = "wasm32")]` module. Native gets types + registration only; wasm32 gets full export machinery. This is correct layering — compiler enforces single-world where it matters (wasm32).
- **wasm32-gated mutual exclusion**: Same reason — the `compile_error!` for multiple features must be wasm32-only so workspace builds don't break.
- **SDK_VERSION const in scaffold**: Hardcoded `"0.21"` as the version string for templates, matching patina-sdk's major.minor. Could use `env!("CARGO_PKG_VERSION")` but SDK version is independent of patina-ai version.
- **`#[macro_export]` macros already crate-root**: Can't re-export them via `pub use` — they're automatically at crate root. Removed from `pub use` lines in lib.rs.
