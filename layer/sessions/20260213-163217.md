**Key Decisions:**
- **Hard-link WIT sync eliminates a class of bugs.** The WIT files in `patina-plugin-api/wit/` are hard links to `wit/`. Editing one edits the other. No manual sync step, no drift. This was discovered mid-implementation (not in the spec).
- **IPv6 bracket handling in validate_http_url.** `url::Url::host_str()` returns `[::1]` for IPv6 (with brackets). `std::net::IpAddr::parse("[::1]")` fails. Fix: strip brackets before parsing. Caught by the IPv6 unit test on first run.
- **Stub impl pattern for WIT-first commits.** Adding WIT import before Host impl forces a stub — bindgen generates a trait that must be implemented. The stub (`Err("not configured")`) keeps each commit compilable while maintaining the 3-commit scalpel plan.
- **No `#[allow(dead_code)]` for validate_http_url.** The function shows a warning in commit 1 (only used by tests) but is consumed by the Host impl in commit 2. Temporary warning is better than suppressing it.

**Patterns Observed:**

- **Spec-driven implementation is fast.** Zero design hesitation during coding. The spec's "Exact Files to Change" table + 3-commit plan turned implementation into fill-in-the-blanks. Total: ~8 files, ~480 lines, clean pre-push.
- **Per [[two-layer-capability-grants]]: load-time AND call-time checks.** `check_capabilities()` validates domain format at load time. Host impl validates domain membership at call time. `validate_http_url()` sanitizes at data level. Three layers, each independently testable.
