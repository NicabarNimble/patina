**Work completed:** Full implementation of [[spec-launcher-tmux]] in two surgical
commits, following the 3-commit plan from last session's continuation prompt.

Commit 1 ([[commit-d47af06f]]): Types, helpers, and tests. Added `TmuxDecision`/
`OffReason` enums to `src/commands/launch/mod.rs` with `resolve_tmux_decision()`
pure function (6 bool params, 7 branches). FNV-1a 32-bit `fnv1a_32()` and
`derive_session_name()` (slug + hash, ≤66 chars). `check_tmux_version()` shells
to `tmux -V`, parses ≥1.9. `--no-tmux` CLI flag on `Cli` struct and `LaunchOptions`.
18 new unit tests covering all decision branches, session name determinism,
truncation, collision resistance, and FNV-1a properties.

Commit 2 ([[commit-d7287d5a]]): Wiring into launcher. Step 9 in `launch()` now
gathers environment (env var, TTY, $TMUX, which, version probe), resolves
`TmuxDecision`, emits targeted warnings for `NotInPath`/`TmuxTooOld`.
`launch_adapter_cli()` conditionally wraps `exec` in
`tmux new-session -A -s <name> -c <path>`. Reconnect hint before exec,
retraction on failure, graceful fallback to direct adapter exec. Non-UTF-8
safe via `.arg(OsStr)`.

**Live testing verified:**
- `--no-tmux` → bypasses tmux, direct adapter launch
- `PATINA_TMUX=0` → bypasses tmux
- `$TMUX` set → skips wrapping (no nesting)
- No TTY (CI/Claude Code session) → correctly skips wrapping via `Off(NoTty)`
- tmux 3.6a installed, version parse works
- Pre-push checks all pass (fmt, clippy, tests)
