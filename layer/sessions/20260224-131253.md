**Key decisions:**

1. **types.rs deferred to [[spec-create]]** — Originally part of this spec, but it had zero callers. Belief [[dead-code-requires-decision]] says no dead code. Updated both spec-create SPEC.md and DESIGN.md to create types.rs as Step 1 instead of assuming it exists.

2. **BumpType delegation impossible** — Spec said `release/mod.rs` should delegate `from_spec_type()` to the types registry. Can't: release is in the lib crate, types.rs is in the bin crate. Match arm stays. Documented in exit criteria.

3. **Visibility split: pub(crate) vs pub(super)** — DESIGN.md said `pub(super)` for all re-exports. Wrong: Rust won't let `spec/mod.rs` widen `pub(super)` to `pub(crate)`. Split re-exports into two tiers — `pub(crate)` for items needing crate visibility (MCP/session), `pub(super)` for items only called from parent function bodies.
