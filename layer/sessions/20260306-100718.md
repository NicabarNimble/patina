### 11:30 - Encryption Gap Discovery
User asked about encrypting all data (at rest + E2EE). Discovered: **spec/design say NOTHING about data confidentiality.** Signing (persona keypair) proves WHO. Hashing (blake3) proves INTEGRITY. Neither prevents READING. events.db stores plaintext JSON. No encrypted Parquet. No E2EE.

Traced encryption placement through separation of concerns from [[session-20260305-224446]]: Pipe doesn't sign, doesn't know persona. Mother OWNS persona. Mother writes to events.db. Therefore **Mother is the correct encryption point** — encrypt at the storage boundary. Model: hash+sign plaintext for dedup/verification, encrypt payload, store encrypted. Consumers decrypt with persona key.

### 12:30 - Bidirectional Pipes + MCP Complementarity
User challenged: "why can't pipes do outbound too?" Correct — pipes transform data, direction is configuration not trait design. **Pipes are bidirectional**: inbound (capture), outbound (push/replicate), sync (P2P). Same SDK, same protocol, same sandbox.

Key distinction: **Pipes = data flow (bulk, batch/stream). MCP server = request-response (interactive queries).** Complementary, not competing. Both needed. MCP server already exists for reads (scry, assay, context) — needs HTTP transport and write tools (emit, believe) for remote apps and edge.

## Key Decisions Made This Session
1. **Pipes are bidirectional** — inbound capture, outbound push, P2P sync. Not just external ingestion.
2. **Pipes are data flow, MCP is request-response** — complementary interfaces, both needed.
3. **Internal transforms are NOT pipes** — they're apps/plugins with opinions. Pipes cross trust boundaries.
4. **Mother encrypts at the storage boundary** — data at rest encryption. Pipe doesn't know about crypto beyond SDK-handled signing/hashing.
5. **Encryption is a spec gap** — signing and hashing exist, confidentiality absent. Must be addressed.
6. **Lakehouse is a Mother-managed service** — not core module, not a traditional "child." Needs to serve multiple consumers.
7. **Patina is a knowledge system** — pipes capture knowledge from sources, not move data between layers. The belief↔reality loop is the product.
