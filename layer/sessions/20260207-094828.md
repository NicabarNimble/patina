### 10:30-10:40 - Fix precision calculation bug
Found root cause: `score_nl_engine()` and `execute_nl()` counted raw doc_id matches
against expected files. Multiple doc_ids from same file (e.g. `engine.rs::fn:query`,
`engine.rs::fn:new`) each counted as separate hits. Fixed by deduplicating retrieved
files before counting.
