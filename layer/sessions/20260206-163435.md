### Patterns Observed

- **Completed specs accumulate** because `spec status complete` doesn't auto-archive. Two-step flow (complete → archive separately) creates drift. Consider: auto-archive on completion, or at minimum prompt.
- **"Active" explores lie** — 8 specs marked `active` in the ready queue but none are being built. Status `active` for explores is misleading. Explores need either a distinct status or exclusion from the ready queue's "ACTIVE" section.
- **Incremental scrape misses frontmatter changes** — when only YAML frontmatter changes (not content hash), incremental scrape skips the file. Required `--full` to pick up status changes. The incremental check should include frontmatter fields.
- **Curate what narrates, generate what enumerates** — build.md was half-stale because it tried to do both. Stories (milestones, architecture, identity) age gracefully. State (spec index, ready queue, dependencies) rots immediately.
