### 19:15 - Deep Research (wasmtime v41 API)
Launched research agent using indexed `bytecodealliance/wasmtime` repo + web docs. Key findings:

1. **wasmtime v41 features confirmed**: `runtime`, `cranelift`, `component-model` all exist and are independent of `async`
2. **wasmtime-wasi `p2` feature enables `wasmtime/async` Cargo feature** — but this is compile-time only, NOT runtime. `Config::async_support(false)` is the default. `add_to_linker_sync()` exists for sync usage.
3. **Phase 1 doesn't need wasmtime-wasi at all** — `mother-child` world only imports `patina:host/log` which we implement ourselves on `HostState`. wasmtime-wasi only needed when plugins use WASI interfaces (`wasi:filesystem`, `wasi:http`).
4. **`wasmtime::component::bindgen!` generates sync code by default** — no `async: true` flag needed. All `call_*()` methods are synchronous. `HasSelf<_>` pattern for host trait implementations confirmed.
