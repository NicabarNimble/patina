**Key discoveries (wasmtime v41 API):**
1. `bindgen!` generates HasData/HostWithStore traits — requires `HasSelf<T>` turbofish on `add_to_linker` for type resolution
2. HostState + Host trait impl MUST live inside the `mod bindings {}` block alongside `bindgen!` — otherwise generates competing Host impls causing trait coherence errors
3. Generated `MotherChild` type collides with our `crate::mother::MotherChild` trait — solved by keeping bindgen in `mod bindings` and bridging via WasmChild adapter
4. `add_to_linker` takes `fn` pointer (not `Fn` closure), with signature `fn(&mut T) -> D::Data<'_>`
5. `call_*` methods take `impl AsContextMut` — needs `&mut *store` reborrow pattern
