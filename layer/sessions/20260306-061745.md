The critical outcome was a major pivot: pipes should be **native processes over stdio** (not WASM), with OS-level sandboxing (macOS sandbox-exec, Linux Landlock) providing security at ~2ms startup vs WASM's ~10s overhead. ### 08:30 - Protocol Independence (commit 4)
[[commit-ad214e36]] — spec(pipe-architecture): JSON-RPC 2.0 self-owned, multiplexing, backpressure

**Key decision: build on JSON-RPC 2.0 (stable RFC), not MCP (evolving product spec).** Self-owned pipe/* methods (pipe/initialize, pipe/fetch, pipe/health, pipe/capabilities, pipe/notify, pipe/shutdown). MCP-compatible but MCP-independent — we own our evolution. WIT defines types natively, not bolted on JSON Schema.

Multiplexing: pipes don't multiplex (unix philosophy). Children demux complex connections (one WebSocket → many pipes). Mother muxes at process level. QUIC/HTTP/2 for network-level multi-stream. Game server example in DESIGN.md.

Backpressure: stdio gets free OS pipe buffer backpressure. HTTP transports use pull-based (Mother controls limit). MessagePack-RPC as binary escape hatch.
