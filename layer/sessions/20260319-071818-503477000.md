**Discussion context:**

Deep archaeology session on the SDK dual-system problem. Started with "explain Mother/Child/Toy" and progressively uncovered that the codebase has two parallel child systems that don't align.

**Key findings:**

1. **`ChildType` is decorative** — the enum (Connector/Transport/Lakehouse/Transform) in `patina-pipe-types` only controls sandbox profile selection (`spawn.rs:116-134`). No method gating, no lifecycle differentiation. All children get the same `Child` trait with all methods.

2. **Two SDKs, two vocabularies** — `patina-sdk` (WASM, `plugin.toml`, `world`, 5 feature-gated worlds) vs `patina-pipe` (native, `child.toml`, `ChildType`, JSON-RPC stdio). Two manifests, two traits, two taxonomies that don't map to each other.

3. **The doctrine says one thing, the code says another** — [[belief:children-have-agency-toys-are-capabilities]] (captured 2026-03-10) established: children = agency (WASM), toys = capabilities. Native DuckLake was killed ([[commit-74586ab1]]). But `github-connector` (native, `patina-pipe`, zero agency) survived — it's doctrinally a toy implementation, not a child, yet uses a `Child` trait from a separate crate.

4. **SDK consolidation (Mar 13, [[commit-ca680391]]) unified WASM side only** — merged `patina-child-sdk` + `patina-toy-sdk` + `plugins/sdk` into single `patina-sdk`. But `patina-pipe` was left outside. The consolidation solved the 3→1 WASM split but didn't address the WASM/native split.

5. **Only one thing doesn't follow the SDK** — every child in the project uses `patina-sdk` except `github-connector`. It's the sole outlier: `patina-pipe` + `child.toml` + native `Child` trait.

**Patterns observed:**
- The Mar 5-6 pipe architecture pivot created `patina-pipe` for native children 3 days before the Mar 10 doctrine crystallized. The doctrine changed the framing but the code wasn't reconciled.
- [[belief:connector-toy-is-indivisible-authority]] describes the connector as a toy, but its implementation uses `Child` vocabulary from a parallel SDK.
- The SDK IS the bible for everything except one native connector that predates the doctrine.
