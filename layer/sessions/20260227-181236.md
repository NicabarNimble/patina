**Key decisions:**
- `tracing-subscriber` file writer with JSON format (not stderr) — MCP protocol purity requires clean stderr
- `collect_rows()` helper centralizes the `.ok()` → `warn!` pattern; `serialize_result()` handles both object and array JSON shapes for `_warnings` injection
- Connection opened unconditionally at startup (SQLite creates empty DB if missing) — simpler than `Option<Connection>` threading
- Error code categorization by handler domain (query engine → missing-index, DB ops → database, everything else → internal) rather than by error message parsing
