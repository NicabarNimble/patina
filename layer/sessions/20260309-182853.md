### 19:16 - Diagnosed embedding bottleneck
`sample` of patina process showed single-threaded ONNX inference in `MlasTrySimpleParallel`. Root cause: three compounding issues in `src/embeddings/onnx.rs` and `src/commands/oxidize/mod.rs`:
1. ONNX session hardcoded to `with_intra_threads(1)` / `with_inter_threads(1)`
2. `embed_batch` was fake — sequential loop, no batched tensors
3. oxidize called `embed_passage` one-at-a-time in a for loop (92k × 3 = 278k calls)

### 19:30 - Created [[oxidize-parallelism]] spec
Fix spec with 11 exit criteria. Outside agent refined the draft: preserve determinism for build mode, split `FastQuery` vs `DeterministicBuild` ONNX modes, keep `with_deterministic_compute(true)` for oxidize, add order-preserving rayon collection, prefix-aware batch APIs, worker cap.

### 20:00 - Implemented [[oxidize-parallelism]] — 3 layers
- **Layer 1:** `OnnxMode` enum — `FastQuery` (auto-threaded, scry/assay) vs `DeterministicBuild` (single-threaded + deterministic, oxidize workers). `create_embedder()` defaults to fast; `create_embedder_deterministic()` for builds.
- **Layer 2:** Real batched ONNX inference — pad/stack into `[batch_size, seq_len]` tensors, single `session.run()`. Prefix-aware `embed_passage_batch` / `embed_query_batch`.
- **Layer 3:** Rayon `par_chunks` + `map_init` in `train_projection` and `build_projection_index`. Per-worker deterministic embedders. Results sorted by original index for deterministic output. Capped at `min(available_parallelism, 8)` workers.

Committed as [[commit-93028a45]].

### 22:00 - Identified next bottleneck: MLP trainer
After embedding parallelism, MLP training is the dominant bottleneck. `src/commands/oxidize/trainer.rs` uses `Vec<Vec<f32>>` for weight matrices — pointer-chasing, no SIMD, no BLAS. 92k triplets × 10 epochs × 768→1024→256 = 2.7M forward passes through scalar loops. ndarray is already a dep but without BLAS features. `matrixmultiply` (pure Rust) is the backend, not Apple Accelerate.

### 22:15 - Created [[trainer-ndarray]] spec
Fix spec: replace `Vec<Vec<f32>>` with `Array2<f32>`, enable ndarray blas feature + `accelerate-src` on macOS, rewrite forward/backprop to use ndarray `dot()` and outer products. 8 exit criteria. Wrote next-session prompt anchored in [[dependable-rust]] and [[unix-philosophy]].
