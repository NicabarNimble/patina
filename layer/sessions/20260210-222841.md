4. **Bug fix: microserver deadlock** ([[commit-aecaf18c]]) — `take(content_length + 1)` in `microserver.rs` caused `read_to_end` to block waiting for 1 extra byte on sockets. Deadlock: server waits for data, client waits for response. This meant `session.rs::uds_post()` always timed out — secrets caching via UDS never worked (fire-and-forget only). Fix: `take(len)` reads exactly Content-Length bytes. Discovered during live testing of AC 3.

**Key decisions:**

- **Secrets over models for first child** — User approved. Models child is a separate spec ([[mother-environment]]) with 6 ACs. Architecture spec just needs "at least one child" to prove the trait. Secrets was cheapest proof.
- **`ChildRequest` uses `action: String` + `payload: serde_json::Value`** — Flexible dispatch that maps to future WIT interface. Children deserialize payload into their own types.
- **`handle(&self)` not `&mut self`** — Spec says concurrent request serving. Children use interior mutability (Mutex) for mutable state. `tick(&mut self)` is single-threaded.
