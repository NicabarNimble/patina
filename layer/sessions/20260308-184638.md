**Key decisions:**
- Sandbox profiles are parameterized by child type, not weakened globally.
  The principle: "scoped access, not broad access." Same as file permissions.
- Mother owns path construction because it's a routing concern (who decides
  where data goes). Lakehouse treats source_path as opaque.
- Bounded batching is the streaming compromise: O(1) transport, O(batch) broker.
  True per-record streaming is future optimization, not v1.
- events.db is NOT a universal audit log. Each scope has its own write side.
  This was implicit before — now explicit in both specs.
