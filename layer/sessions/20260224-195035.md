**Key decisions:**
1. **No registry (types.rs)** — BumpType can't cross lib/bin boundary, identity mapping doesn't need abstraction, only 2 consumers
2. **No SpecFrontmatter migration** — `r#type` stays `String`, no serde churn
3. **Add thin `SpecType` enum to `src/spec.rs` (lib)** — `FromStr` + `as_str()`, ~30 lines, first consumer is create.rs
4. **Skip `directory()` method** — use `as_str()` directly since mapping is 1:1 identity today
5. **Add `SPEC_TYPES` constant** — single source for error messages, help text, tests
6. **Explicit parse error** — `SpecTypeError` with allowed values in message
7. **Ship spec-create with enum** — both fit in one session, enum earns its keep immediately

**Patterns observed:**
- "Boundary stays string, internal stays typed" is the standard adapter pattern for WASM/WIT — same principle as [[dependable-rust]] (stable external interface, typed internals)
- Outside review agents with less project context still surface valid architectural challenges — the "why is this in bin?" probe was the key unlock
- Three-way review (builder → domain expert → architecture expert) converges faster than single-pass
