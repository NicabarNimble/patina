### 11:10-11:25 - Phase 2: Intent-aware weighting

**Step 1: Suppress semantic/persona for General (25 queries)**
Set semantic=0.0, persona=0.0 for General intent. Both contribute 0% across all
52 NL queries with E5-base-v2. Result: NL P@10 33.3% → 36.4% (+3.1pp), test held
at 34.2%.

**Step 2: Suppress semantic/persona for ALL intents + redirect dead boosts**
Extended suppression to all 5 intents. Redirected Mechanism's dead `semantic: 1.5`
boost to `lexical: 1.5`. Results:
- NL P@10: 33.3% → 37.7% (+4.4pp), test: 34.2% → 37.5% (+3.3pp)
- Co-change P@10: 58.2% → 73.1% (+14.9pp)
- Belief MRR: 0.169 → 0.241 (+0.072)
- Mechanism MRR: 0.160 → 0.493 (+0.333) — biggest single-intent improvement
- D1 verdict: PASS

Applied [[andrew-ng-over-shoulder]] checklist: measurement truthful (yes), improvement
real (test set validated), would survive held-out (test P@10 +3.3pp). All pass.

### Patterns Observed
- **Removing noise beats adding signal** — suppressing 0% oracles improved everything
  more than boosting non-zero oracles. The RRF algorithm means useless results actively
  harm ranking by diluting scores.

  didn't generalize (test held flat), while all-intent suppression did (test improved).
  The split paid for itself immediately.
