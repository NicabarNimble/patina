1. **Architecture review** — Read 20+ files across `crates/patina-pipe/`, `src/broker/`, `src/connect/`, `children/github-connector/`, `src/commands/`, `src/http_util.rs`, `src/secrets/`, `src/paths.rs`. Traced full flow: `patina connect github` → `patina mother run <source>`. Identified 5 seams, graded alignment against [[dependable-rust]], [[unix-philosophy]], [[safety-boundaries]].

2. **First audit correction** — Outside agent caught 6 issues my review missed or understated:
   - **High:** Sandbox computed but not applied (`src/broker/spawn.rs:186` `let _ = &sandbox_profile;`). My review falsely claimed "child is sandboxed."
   - **Medium:** `compute_status()` never returns `Connected` (new connections have `last_validated: None`, nothing sets it). `Missing` variant never produced.
   - **Medium:** Non-atomic `create()` — TOML before vault. Vault failure leaves orphan TOML.
   - **Medium:** Child process leak — `fetch()?` skips `shutdown()`, `Drop` on `Child` detaches.
   - **Medium:** `source_id` collision — `"child:{child_name}"` shared by multiple sources using same child binary.
   - **Low:** Lake routing is a runtime `bail!()`.

3. **Spec creation** — Initially created as `connect-hardening` ([[commit-d6be47a7]]), renamed to `runtime-hardening` via `mv` + frontmatter update (no spec rename command exists — filesystem-driven system handles it cleanly).

4. **Second audit correction** — Outside agent reviewed the spec and caught 5 more issues:
   - `Drop` can't call `wait(self)` — redesigned to `cleanup(&mut self)` with kill+try_wait only
   - Drop shouldn't do I/O — removed `pipe/shutdown` from Drop, kept it as explicit normal-path only
   - Refresh overwrites old secret — added credential snapshot + restore-on-rollback
   - Registry ≠ vault — weakened exit criterion from "vault entry absent" to "registry entry absent"
   - Manual tokens aren't validated — `last_validated` only set when `account_id.is_some()`

**Key decisions:**
- [[spec-runtime-hardening]] is a fix spec, not a refactor — these are bugs, not cleanup
- Spec covers ALL 8 findings (including 2 I initially dropped: dependency cycle, lake stub)
- Drop is fail-safe only (kill+reap). Graceful shutdown stays in explicit code paths.
- `resolve_child_binary` moves to `src/children.rs` (not `paths.rs` — paths is I/O-free per [[dependable-rust]])
- Lake `Destination::Lake` variant stays in enum for forward compat, rejection moves to parse time
