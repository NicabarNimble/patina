**Error analysis (per [[andrew-ng-over-shoulder]]):**
Ran `patina eval --scry` and studied all 20 queries. Ran individual `patina scry` queries on Q1 ("ripple effects"), Q2 ("public API surfaces"), Q13 ("index matters more than model"), Q18 ("evaluation queries independent"). Diagnosed two root causes:

1. **Broken gradient computation** — `trainer.rs:update_weights()` had layer 1 as constant decay (`lr * 0.001` = 0.000001 subtracted from every active weight, not a gradient), and layer 2 missing L2 normalization Jacobian with `* 0.01` damping making effective learning rate 0.00001. The MLP literally could not learn.

2. **Training pair mismatch** — commit-function triplets (anchor: commit message, positive: function in touched file, negative: function in untouched file) don't teach the vocabulary gap bridging that the eval measures (conceptual NL query → belief/pattern document).
