- **[[commit-aa4491e4]]**: Enforcement tooling. Fixed 7 stale host.wit copies across world dirs (command, task, pipeline) and guest crates (command-api, task-api, pipeline-api) — all now hard-linked to canonical `wit/deps/patina-host/host.wit`. Added pre-push step `[2/5]`: checks all 7 copies share canonical inode (Strategy 1 — inode identity), falls back to content diff (Strategy 2) to distinguish "not linked but matching" from "split-brain divergence." Strengthened belief from `entrenchment: medium` → `high`.

**Key Decisions:**
- **Dual-strategy enforcement.** Strategy 1 (inode) is fast and precise but fragile on exotic filesystems. Strategy 2 (content diff) is portable. Pre-push does Strategy 1 first; if inodes differ, falls back to Strategy 2 to give the right diagnostic: WARN (matching content, wrong link) vs ERROR (split-brain divergence). This was the outside agent's recommended approach.
- **Check guest crates too, not just world dirs.** Initially only checked the 4 world dirs. Pre-push step 1 (existing WIT consistency check) caught that `patina-command-api/wit/command/deps/patina-host/host.wit` was also stale. Extended the hard link check to cover all 7 copies — the enforcement is only real if it's complete.
- **Beliefs without enforcement are vibes.** This principle, articulated by the outside agent, became the core of the strengthened belief. The original [[wit-hard-links-not-copies]] belief was correct but never enforced — which is why 7 copies drifted silently. The enforcement check makes it an invariant, not an aspiration.

**Patterns Observed:**
- **Incident → belief → enforcement is the full cycle.** Capturing [[wit-deps-must-be-hard-links-verified]] as a belief was step 1, but the outside agent correctly identified that enforcement tooling is the real fix. The belief now references its own enforcement code — self-documenting invariant.
- **Schema changes need migration discipline.** The outside agent framed host.wit edits as "DB migrations for the plugin ecosystem." This is the right mental model — any change to the canonical host.wit must propagate to 7 hard-linked copies, or the build will break (not now, but when someone adds the next import).
