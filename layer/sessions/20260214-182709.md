**Work completed:** Built and validated [[grammar-extraction]] Phase 2 end-to-end. All exit criteria met.

1. **Installed wasi-sdk 30** to `~/.local/share/wasi-sdk/` (downloaded from GitHub releases, arm64-macos). Provides clang, llvm-ar, and wasi-sysroot for cross-compiling C to wasm32-wasip2. Could not install to `/opt/wasi-sdk` (no sudo), used `~/.local/share/` instead.

2. **Built grammar-rust/ plugin** ([[eb66430b]]): Self-contained pipeline plugin outside workspace.
   - `build.rs` — compiles tree-sitter-rust parser.c + scanner.c via `cc` crate with wasi-sdk as C compiler
   - `src/lib.rs` — PipelinePlugin impl, full extraction logic ported from `languages/rust.rs` (richest processor: functions, types, imports, constants, members, call edges, macros, impls)
   - `.cargo/config.toml` — CC/AR/CFLAGS env vars pointing to wasi-sdk
   - Vendored C grammar sources from `patina-metal/grammars/rust/src/`
   - Built: **1.4MB WASM component** from 5.8MB parser.c source (4x compression)

3. **Fixed two bugs** ([[6981fdbe]]):
   - **Linker override killed component model**: Setting `linker = wasm-ld` produced core WASM modules (version 0x1), but wasmtime needs WASM components (version 0x1000d). Removing the override lets the default `wasm-component-ld` produce components. Only CC/AR/CFLAGS needed for wasi-sdk.
   - **Impl double-processing**: `process_impl` recursed into body children, then the general recursion did too. Fixed by returning early after `process_impl` to skip the general recursion.

4. **Discovered plugin.wasm naming convention**: Plugin discovery expects exactly `plugin.wasm`, not `grammar_rust.wasm`. Had to rename after first failed dispatch.

5. **Benchmarked on 238-file patina repo**: Plugin vs compiled-in comparison:
   - Time: 6.2s vs 3.4s = **1.82x overhead** (well within 10x decision gate)
   - Functions: 2292 vs 2238 (+2.4% — plugin finds more from module internals)
   - Types: 948 vs 588 (+61% — plugin captures `mod` items as types)
   - Call edges, constants, members: near-identical

**Key decisions:**
- Used `~/.local/share/wasi-sdk/` for local development — `.cargo/config.toml` has hardcoded paths. Users must customize or set env vars. README documents the portable approach.
- Kept tree-sitter 0.24 to match patina-metal's version (0.26.5 available but not needed)
- Plugin extracts `mod_item` as types — net improvement over built-in which skips modules

**Challenges faced:**
- wasi-sdk not in homebrew — manual download + install
- WASM module vs component: linker override silently produced wrong format. Only caught when wasmtime rejected the binary. Root cause: `wasm-ld` is the raw WASM linker, `wasm-component-ld` wraps core modules into components.
- Plugin discovery expects `plugin.wasm` not crate-named `.wasm` — not documented, found by reading `src/plugin/internal/pipeline.rs`
