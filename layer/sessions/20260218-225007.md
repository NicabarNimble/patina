**Root cause diagnosed:** `patina launch` over SSH (Tailscale + Termius iOS → Mac Studio) was failing to inject `CLAUDE_CODE_OAUTH_TOKEN` because `src/secrets/keychain.rs` stored the age identity with the default `WhenUnlocked` Keychain policy. macOS Keychain is not accessible in SSH sessions when the screen is locked — `get_generic_password` returns `errSecInteractionNotAllowed`, caught silently in `try_get_claude_token()`, no token injected.

**Key decision — [[keychain-always-this-device-only]]:** Chose `kSecAttrAccessibleAlwaysThisDeviceOnly` over all alternatives:
- `PATINA_IDENTITY` env var rejected — plaintext private key on disk defeats vault security model
- `AfterFirstUnlock` rejected — still fails post-reboot until someone logs in (wrong for headless Mac Studio)
- Plaintext file rejected — same exposure as above
- `AlwaysThisDeviceOnly` chosen: hardware-encrypted in M-chip Secure Enclave, accessible always, device-bound (no iCloud sync), deprecated only on iOS (stolen phone threat model doesn't apply to stationary Mac)

**Why Touch ID can't work over SSH:** Touch ID is a local GUI event rendered by WindowServer. SSH has no display. No protocol exists to proxy a biometric challenge from Termius on iOS to the Mac's Keychain. This is architectural, not fixable with config.

**Implementation — [[commit-1df40fff]]:** `kSecAttrAccessibleAlwaysThisDeviceOnly` absent from `security_framework::ProtectionMode` enum (iOS deprecation). Called `SecAccessControlCreateWithFlags` directly via `security_framework_sys`. Required `core_foundation::base::TCFType` in scope for `wrap_under_create_rule` — added `core-foundation = "0.10"` and `security-framework-sys = "2.16"` as explicit macOS deps. Delete-before-add pattern handles both fresh install and policy upgrade of existing items.

**Migration — [[commit-a086aeee]]:** `setup_claude()` re-stores existing identity after token save via `export_identity()` + `import_identity()`. Existing users migrate by re-running `patina secrets setup-claude` once.

**Knowledge preserved — [[commit-14af96d1]]:** Created [[spec-secrets-keychain-ssh]] documenting the full decision tree, all rejected alternatives, Secure Enclave security model, machine migration steps, and threat model table. Created belief [[keychain-always-this-device-only]] with defeated attacks (PATINA_IDENTITY plaintext, deprecation objection, AfterFirstUnlock). Updated stale SSH platform row in [[spec-launcher-auth]].
