## Decisions

- **Mother has internal services + external children** — not "everything is a child." Native capabilities (secrets, sessions, health) are Mother-internal modules, not children in the registry. Grounded in [[four-roles-no-overlap]].
- **Sessions are Patina protocol, not Mother infrastructure** — artifacts in `layer/sessions/` are knowledge capture. Mother only tracks session state for federation/awareness. The session-writer "child" was removed.
- **HTTP is Mother's single transport** — deleted protocol v1 socket handler. UDS for local, TCP for remote, both HTTP.
- **MotherChild trait fully retired** — including WASM engine, SDK API, and legacy plugins. `KnowledgeChild` is the only child trait.
- **Grammar pipeline keeps "plugin" vocabulary** — "grammar plugin" is a domain term for WASM processors, not a Patina child. Bucket B in vocabulary retirement is compat-keep.
- **`plugins/` directory is not moved in vocabulary spec** — physical topology consolidation is a separate concern from vocabulary cleanup.
