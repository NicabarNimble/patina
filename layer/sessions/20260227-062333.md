**Key decisions:**
- spec.show returns *structure* not *content* by default — the LLM gets the
  heading outline (navigable table of contents) plus file paths for targeted
  reads. This respects [[unix-philosophy]]: one tool for structure, Read tool
  for content.
- Area 4 freshness thresholds are hardcoded constants, not configurable.
  Measure is opinionated about what "healthy" means — configuration adds
  complexity for zero demonstrated need.
- Area 5 prefers `git diff` over mtime for file-skip in code scraper —
  exact (piggybacks on git's tree comparison) vs unreliable (mtime resets).
