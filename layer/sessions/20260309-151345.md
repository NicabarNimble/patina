**Key decisions:**
- Provider trait is object-safe (`Box<dyn Provider>`) — enables dynamic dispatch from registry without generics leaking into the connect module public API.
- `GITHUB_CLIENT_ID` is a placeholder constant — per DESIGN.md Open Question 1, code is fully testable without a real OAuth App registration.
- Browser open is best-effort with `let _ = open_browser()` — user code is always displayed via stderr, so browser failure doesn't block the flow.
- `probe_account()` failures in `acquire()` and `acquire_manual()` are warnings, not errors — the credential is still valid even if the identity probe fails.
- Provider defaults (`default_scopes`, `default_child`, `allowed_domains`) match `children/github-connector/child.toml` exactly — test verifies this alignment.
