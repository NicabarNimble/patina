# Session Capture

Capture development context with minimal friction. Scripts handle mechanics (timestamps, git state, file tracking). Humans handle meaning (goals, decisions, insights). Progressive detail — start simple, enhance later.

## Test

Can a developer start capturing context in under 10 seconds? If setup friction exceeds that, developers won't capture.

## Consequence

Natural documentation emerges from development work. Context is preserved for future sessions without interrupting flow. Patterns surface from accumulated sessions and become candidates for promotion.
