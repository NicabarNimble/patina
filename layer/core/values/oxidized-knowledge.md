# Oxidized Knowledge

Knowledge accumulates through use, separated into project knowledge (git-tracked, shared) and persona knowledge (machine-local, personal).

## Test

Is this knowledge about the project or about the person? If project, it goes in `layer/` (git-tracked). If personal, it goes in `~/.patina/layer/` (local-only).

## Consequence

Project knowledge is shared and reviewable via git. Personal beliefs are private and portable. Mixing the two contaminates shared knowledge with personal preferences or hides project decisions in local-only storage.
