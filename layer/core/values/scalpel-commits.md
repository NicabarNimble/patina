# Scalpel Commits

Commit with a scalpel while working, not with a shotgun after everything is tangled together.

## Test

Can each commit be reviewed, reverted, and explained as one coherent step? If not, split the work before committing.

## Consequence

Git history becomes usable evidence. Risky work can checkpoint safely, reviewers can reason about intent, and later recovery does not require untangling unrelated changes.
